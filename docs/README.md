# Versão web do dashboard

O painel web está em `docs/index.html`.

## Publicação

O repositório já contém um workflow para publicar o conteúdo de `docs/` no GitHub Pages.

No GitHub, abra:

**Settings → Pages → Source: GitHub Actions**

Depois execute o workflow **Publicar Dashboard Web** em **Actions**.

A URL gerada pelo GitHub será compartilhável com toda a equipe.

## O que a equipe pode revisar

A versão v1 reúne no mesmo painel:

- Visão geral;
- comparação AMAWeb × AccessMonitor;
- qualidade da coleta;
- Ouvidorias;
- detalhe individual.

Os resultados individuais não são separados em dashboards diferentes. Eles são acessados pelos filtros e pela área de detalhe.

Esta é uma versão de revisão metodológica e visual.
