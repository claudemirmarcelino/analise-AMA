Todos os resultados individuais ficam dentro deste mesmo dashboard. O usuário filtra por entidade, município ou situação e, quando necessário, desce até o detalhe. Avaliações não utilizáveis não são transformadas artificialmente em nota zero. Este painel é uma versão de trabalho para discussão da equipe.
